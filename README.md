# 🔥 Análise de Queimadas no Brasil

Dashboard interativo para análise dos focos de queimadas no Brasil entre 2015 e 2024.

## 📊 Tecnologias
- Python
- Pandas
- Plotly
- Streamlit

## 🔗 Links

- [GitHub Pages](https://caioferamorim.github.io/projeto-queimadas-brasil)

- `app.py` — Dashboard Streamlit
- `dados/` — Base de dados
- `notebooks/` — Análise exploratória
