🔥 Análise de Queimadas no Brasil

Dashboard interativo — 2015 a 2024

📋 Sobre o Projeto

Este projeto analisa os focos de queimadas no Brasil entre 2015 e 2024, identificando padrões regionais, sazonalidade e áreas críticas. Desenvolvido com Python, Pandas, Plotly e Streamlit.

🎯 Objetivos

  • Identificar estados mais afetados pelas queimadas
  • Analisar tendências temporais entre 2015 e 2024
  • Investigar sazonalidade dos focos
  • Comparar regiões e biomas
  • Identificar períodos críticos

🛠️ Tecnologias

  • Python — linguagem principal
  • Pandas — manipulação de dados
  • Plotly — visualizações interativas
  • Streamlit — dashboard web

📊 Visualizações

  • Evolução temporal dos focos por ano
  • Comparação entre estados
  • Análise por bioma
  • Heatmap de sazonalidade mensal
  • Correlação entre seca e queimadas
  • Tabela dinâmica interativa
